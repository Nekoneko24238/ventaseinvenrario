# Inventory Flow

Créame una aplicación de control de inventario con control de ventas que deje seleccionar como se vendió efectivo, divisas, en caso de pagomovil que deje agregar un número de referencia de 4 digitos, registros completo y control contable y sistema de impresión de facturas

Implementa un sistema de usuarios con roles para controlar quién puede ver inventario, ventas y contabilidad

Con base de datos totalmente local.
